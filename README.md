# T-Shirt Design Studio 🎨👕

A powerful web-based T-shirt design tool built with Vue.js 2 and Fabric.js 4.6. Create professional custom T-shirt designs with advanced text, image, and shape editing capabilities.

## 🚀 Features

### 🛠️ Core Features
- Built with Vue.js 2 and Fabric.js 4.6
- Intuitive toolbar and comprehensive properties panel
- Responsive design that works on desktop and tablet

### 🖼️ Image Editing
- Upload and drag custom images from your computer
- Add stickers & random images
- Advanced image filters:
  - Light adjustments: Brightness, Contrast, Exposure
  - Color adjustments: Saturation, Vibrance, Hue Rotation
  - Effects: Blur, Noise, Pixelate, Sepia
  - Filters: Grayscale, Invert, Polaroid, Vintage, Kodachrome, Technicolor
- Image cropping tool with adjustable selection
- Background removal and transparency support

### ✏️ Text Editing (Advanced)
- Add and customize text with extensive styling options:
  - Font family selection (15+ fonts)
  - Complete typography controls:
    - Font size (8px-120px)
    - Font weight (9 options from Thin to Black)
    - Line height and letter spacing
    - Text alignment (Left, Center, Right, Justify)
  - Text decoration: Bold, Italic, Underline, Strikethrough, Overline
  - Text background with adjustable opacity
  - Text stroke (outline) with customizable width and color
  - Text shadow with configurable blur and offset

### ⚙️ Shape & Object Tools
- Add and customize shapes (rectangles, circles, triangles, polygons)
- Shape properties:
  - Fill color with opacity control
  - Stroke (border) with customizable width, color, and style (solid/dashed/dotted)
  - Corner radius for rounded shapes
  - Shadow effects
- Transform tools for all objects:
  - Rotation (0°-360°)
  - Scaling (X and Y axis independently)
  - Opacity control

### 🎨 Drawing Tools
- Freehand drawing with pencil tool
- Adjustable brush size (1px-20px)
- Customizable brush color
- Pressure sensitivity support (for supported devices)

### 💾 Export & Sharing
- Save designs locally
- Download designs in multiple formats:
  - High-quality PNG
  - Print-ready PDF
  - SVG vector format (coming soon)
- Social media sharing integration
